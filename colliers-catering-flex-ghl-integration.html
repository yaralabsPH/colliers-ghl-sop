The rule

Flex is the source of truth. When customer, order, or company information changes in Flex, the integration automatically updates the matching records in GoHighLevel.

What triggers what

Event in Flex Result in GHL How it works
Create Customer →Creates Contact The integration sends the customer into GHL and stores the Flex Customer UUID/ID on the contact so both systems stay linked.
Update Customer →Updates Contact Changes to the customer record are pushed to the existing GHL contact instead of creating a duplicate.
Create or Update Order →Updates Customer Metrics GHL recalculates and updates fields such as Order Count, Lifetime Value, First Order Date, Last Order Date, and Latest Order Date.
Create Company →Creates Company The Flex company is linked to a GHL company/business record.
Update Company →Updates Company Company details and company-level order metrics are refreshed automatically.

Key principles

One-way sync

Data flows Flex → GHL only. The integration never changes or deletes anything inside Flex.

Real-time + backup

Real-time webhooks handle changes immediately. A separate 5-minute reconciliation process also checks for missed updates, acting as a backup recovery layer.

Fully logged

All synchronization activity — successful events and errors alike — is recorded in the integration Google Sheet for monitoring and troubleshooting.
